A Streamlit application for localizing noise sources from multichannel microphone-array recordings. It explores DAS, MVDR, CMF, and SODIX beamforming algorithms with comparison views and acoustic maps.

`Python` · `Streamlit` · `Acoular` · `NumPy` · `Signal Processing`
