# Profile assets

GIFs and images used by the profile `README.md`.

Drop files here rather than hotlinking from Giphy, Tenor or other external hosts.
External URLs rot — they get rate-limited, moved or deleted, and the profile
silently ends up with broken images. Files committed here render forever.

## Suggested files

| Filename | Purpose |
| --- | --- |
| `hero.gif` | Right-floated animation beside the About section |
| `divider.gif` | Optional thin animated divider between sections |

## Referencing them

Use a path relative to the repository root:

```html
<img align="right" width="300" src="assets/hero.gif" alt="" />
```

## Keep them small

Aim for **under 2 MB** per GIF. Large files make the profile slow to load on
mobile connections, and GitHub does not resize or optimise them.
